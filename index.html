# 📋 Passo a Passo — Atualizar o App com os 2 Módulos --- ## 📁 O que você vai ter no final: ``` 📁 financas-familia/ ├── 📄 index.html ← App principal (receitas/despesas) ├── 📄 dividas.html ← Módulo de dívidas (NOVO) ├── 📄 manifest.json └── 📄 sw.js ``` --- ## 🔧 PARTE 1 — Atualizar o index.html --- ### Passo 1 — Abrir o arquivo atual ``` 1. Vá até a pasta: financas-familia (na sua Área de Trabalho) 2. Clique com botão direito no arquivo: 📄 index.html 3. Clique em: "Abrir com" → "Bloco de Notas" ``` --- ### Passo 2 — Apagar o conteúdo atual ``` 1. Dentro do Bloco de Notas pressione: Ctrl + A (seleciona tudo) 2. Pressione: Delete (apaga tudo) 3. A tela fica em branco ✅ ``` --- ### Passo 3 — Colar o novo código ``` 1. Copie TODO o código da versão corrigida (o código grande com fixos + confirmação de pagamento que foi gerado na resposta anterior) 2. Cole no Bloco de Notas: Ctrl + V 3. Salve: Ctrl + S 4. ✅ index.html atualizado! ``` --- ## 🆕 PARTE 2 — Criar o dividas.html --- ### Passo 4 — Criar novo arquivo ``` 1. Abra um NOVO Bloco de Notas (sem fechar o outro) 2. Copie TODO o código do módulo de dívidas (o código com Gestão de Dívidas & Negociação Serasa) 3. Cole no novo Bloco de Notas: Ctrl + V ``` --- ### Passo 5 — Salvar como dividas.html ``` 1. Clique em: Arquivo → Salvar Como 2. Navegue até a pasta: financas-familia 3. Preencha: Nome do arquivo: dividas.html Tipo: Todos os arquivos (*.*) Codificação: UTF-8 4. Clique em: Salvar ✅ ``` --- ## 🔗 PARTE 3 — Conectar os dois arquivos ### Passo 6 — Adicionar botão no index.html ``` 1. Abra o index.html no Bloco de Notas 2. Use Ctrl + F para buscar: 3. ANTES do cole este código: ``` ```html 💳 Dívidas Serasa ``` ``` 4. Salve: Ctrl + S ✅ ``` --- ### Passo 7 — Adicionar botão de voltar no dividas.html ``` 1. Abra o dividas.html no Bloco de Notas 2. Use Ctrl + F para buscar: 3. ANTES do cole este código: ``` ```html 🏠 Voltar ao App ``` ``` 4. Salve: Ctrl + S ✅ ``` --- ## 🌐 PARTE 4 — Subir para o GitHub Pages --- ### Passo 8 — Acessar o GitHub ``` 1. Acesse: https://github.com 2. Faça login na sua conta 3. Clique no repositório: financas-familia ``` --- ### Passo 9 — Atualizar o index.html no GitHub ``` 1. Clique no arquivo: index.html 2. Clique no ícone de lápis ✏️ (canto superior direito do arquivo) 3. Selecione TUDO: Ctrl + A 4. Delete tudo 5. Cole o novo código: Ctrl + V 6. Role até o final da página 7. Em "Commit changes": Mensagem: "Atualização: fixos + pagamentos" 8. Clique em: "Commit changes" ✅ ``` --- ### Passo 10 — Criar dividas.html no GitHub ``` 1. No repositório, clique em: "Add file" → "Create new file" 2. No campo "Name your file": Digite: dividas.html 3. Na área de texto grande: Cole TODO o código do dividas.html 4. Role até o final 5. Em "Commit changes": Mensagem: "Novo: módulo de dívidas Serasa" 6. Clique em: "Commit changes" ✅ ``` --- ### Passo 11 — Atualizar sw.js ``` 1. No repositório, clique em: sw.js 2. Clique no lápis ✏️ 3. Substitua o conteúdo por: ``` ```javascript const CACHE_NAME = 'financas-v2'; const FILES = [ './', './index.html', './dividas.html', './manifest.json' ]; self.addEventListener('install', e => { e.waitUntil( caches.open(CACHE_NAME).then(c => c.addAll(FILES)) ); self.skipWaiting(); }); self.addEventListener('activate', e => { e.waitUntil( caches.keys().then(keys => Promise.all(keys.filter(k => k !== CACHE_NAME).map(k => caches.delete(k))) ) ); }); self.addEventListener('fetch', e => { e.respondWith( caches.match(e.request).then(r => r || fetch(e.request)) ); }); ``` ``` 4. Commit: "Atualizar service worker v2" ✅ ``` --- ## 📱 PARTE 5 — Atualizar no Celular --- ### Passo 12 — Limpar cache e atualizar #### Android: ``` 1. Abra o Chrome 2. Acesse o link do seu app: https://SEU-USUARIO.github.io/financas-familia 3. Aperte: ⋮ (3 pontinhos) 4. Clique em: "Atualizar" ou segure o ícone 🔄 para forçar atualização 5. Se tiver instalado como app: → Desinstale o app da tela inicial → Acesse o link novamente → Reinstale: ⋮ → "Adicionar à tela inicial" ``` #### iPhone: ``` 1. Abra o Safari 2. Acesse o link do app 3. Toque em: □↑ Compartilhar 4. "Adicionar à Tela de Início" 5. Substitui o ícone anterior ✅ ``` --- ## ✅ Verificação Final ``` Após atualizar, confirme que: ✅ index.html abre normalmente ✅ Botão "💳 Dívidas Serasa" aparece no canto ✅ Ao clicar vai para dividas.html ✅ Em dividas.html aparece botão "🏠 Voltar" ✅ Fixos aparecem em todos os meses ✅ Confirmação de pagamento funciona ✅ Dívidas salvam corretamente ``` --- ## 🆘 Problemas Comuns | Problema | Solução | |---|---| | Arquivo salvo como `.html.txt` | Selecione "Todos os arquivos" ao salvar | | Botão de dívidas não aparece | Verifique se colou antes do `` | | GitHub não atualiza | Aguarde 2-3 minutos após o commit | | App no celular não atualiza | Desinstale e reinstale na tela inicial | | Dados sumiram | Estão salvos no localStorage — não apague dados do site | --- > 💬 **Me diga em qual passo travou que te ajudo!** 😊
